# Fortune Cookie Wisdom for Developers

A make.fun bounty entry: one program (`main.ts`, Node 22, no dependencies,
no network) writes a single original line of fortune-cookie wisdom for a
software developer to `/output/entry.txt`.

Built for make.fun's ["Fortune Cookie Wisdom for Developers" bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) ($2 in USDC, split over the top two).

The line is my own, written in this session:

> The stranger who will maintain your code is you, six months from now — leave them a map, not a maze.

(100 characters.) It reads like a real fortune cookie — a warning wrapped
in a blessing — it is true about a developer's day (maintaining old code,
including your own), and the map-not-maze turn is the fresh part: the
stranger inheriting your code is your future self.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fortune-cookie-out node main.ts
cat /tmp/fortune-cookie-out/entry.txt
```
